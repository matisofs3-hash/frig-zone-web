# Abrir el proyecto en VS Code

Doble clic en este archivo o ejecutalo en PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\Familia\Desktop\FrigZone - Deep\abrir_vscode.ps1"
```

El script abre VS Code con la carpeta `frigzone-web` y el `index.html`.

## Qué vas a ver

- **Explorador:** 26 páginas HTML, `assets/`, `_src/` (el generador) y `.vscode/`.
- **Control de código fuente:** el repo con 4 commits en la rama `main`.
- **Tareas:** `Ctrl+Shift+B` para regenerar el sitio; `Terminal → Run Task` para QA, servidor y flyers.
- **Live Server:** clic derecho sobre `index.html` → *Open with Live Server*.

## Extensiones recomendadas

VS Code te va a sugerir instalarlas al abrir la carpeta:

- Python
- Live Server
- GitLens
- Markdown All in One
